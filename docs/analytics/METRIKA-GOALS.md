# Canfly — цели Яндекс Метрики (счётчик 42420764)

## Зачем

Просмотры не показывают, интересны ли пользователям произведения. Реальные
целевые действия на публичной странице Release отслеживаются отдельно и
не содержат имён, ID пользователей, текста книг или персональной информации.

## Настройка в интерфейсе Яндекс Метрики

Счётчик 42420764 → **Цели → Добавить цель → Целевое событие**.
Для каждой цели выбрать условие **совпадает** и указать точный идентификатор:

| Название | Идентификатор события | Что означает |
| --- | --- | --- |
| Открытие издания | `edition_open` | Посетитель нажал внутреннюю ссылку издания (читалка/медиа) |
| Начало разговора с персонажем | `character_chat_open` | Посетитель нажал «Поговорить» в блоке персонажей релиза |
| Переход к внешнему изданию | `external_edition_open` | Посетитель нажал ссылку на внешнее издание |

Цели регистрируются в интерфейсе Яндекса отдельно от развёртывания кода.
Имеющийся у MCP токен `metrika:read` не позволяет создавать цели.
Текущий код не добавляет/не меняет настройки счётчика через API.

## Как проверить

1. Убедиться, что цели созданы в интерфейсе Метрики с *точными* ID.
2. В браузере без блокировщика рекламы открыть **опубликованный** релиз,
   нажать «Начать читать», «Поговорить» либо внешнее издание.
3. Через несколько минут проверить конверсии целей в Метрике. В DevTools можно
   проверить отправку обращения к `mc.yandex.ru` после клика.
4. Проверить, что на приватной странице `/studio` цели не отправляются.
5. Не делать выводов по собственным кликам; отделять тестовые посещения
   от реального трафика.

## Ограничения

- Это отслеживание **клика**, а не подтверждённого открытия книги,
  чтения главы, успешного ответа персонажа или покупки на внешнем сайте.
- Счётчик может быть заблокирован настройками приватности и расширениями.
- Сбор целей не применяется к уже прошедшим визитам.
- События отправляются только при наличии глобального `ym`.
- В коде пока нет отдельных целей завершения чтения, регистрации или покупки.
- До измерения результатов по целям нельзя оценивать конверсию перехода
  в полноценное чтение.
