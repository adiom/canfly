# MCP

Проверено по [коммиту](README.md). **Факт:** [`/api/mcp`](../../app/api/mcp/route.ts) создаёт MCP handler и регистрирует инструменты из [`lib/mcp/tools/`](../../lib/mcp/tools/): персонажи, связи, главы, релизы, поиск, места, серии, Метрика, Webmaster. Серверная авторизация поддерживает статический токен либо OAuth; реализация OAuth — [`lib/server/mcp-oauth.ts`](../../lib/server/mcp-oauth.ts), HTTP-маршруты — [`app/api/oauth/mcp/`](../../app/api/oauth/mcp/). Схема тестовой БД включает `mcp_oauth_clients`, `mcp_oauth_codes`, `mcp_oauth_grants`, `mcp_oauth_refresh_tokens`, `mcp_oauth_events`.

**Факт:** инструменты контента работают с БД напрямую и не наследуют ownership-проверки Studio; барьер доступа находится на входе MCP. Часть инструментов меняет данные. Каталог документации не является MCP resource: **план** будущей интеграции — отдавать эти Markdown-файлы как версионированные read-only ресурсы с путём и SHA, без секретов и дампов. До отдельного ADR сервер и поисковый индекс не добавляются. Дополнительное описание существующего API — [docs/MCP.md](../MCP.md), но текущий код имеет приоритет.
