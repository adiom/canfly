# Утверждённый базовый Release

Утверждено 5 ноября 2026. Визуальный эталон: [approved-desktop.png](./approved-desktop.png).

- Верх: обложка, один H1, авторы при наличии, серия, аннотация с раскрытием.
- Внутренние издания: формат, собственные метаданные и действие чтения, прослушивания или просмотра.
- Основная область: персонажи и публичные работы читателей. Боковой контекст: серия, связанные релизы, игры и места.
- Внешние цифровые издания: нижняя полоса «Выберите своё издание».
- На desktop границы контента совпадают с левым краем логотипа и правым краем «Цвета». Растровый эскиз приблизителен; это правило выравнивания имеет приоритет.
- На mobile — естественная прокрутка, читаемый текст, полные действия без горизонтального переполнения.
- Цвета наследуются от глобального Toggle theme и cf-*; индивидуальный design_config не применяется. Сохранённые значения не удаляются из БД.
- Пустые разделы отсутствуют. Большие списки и описания раскрываются нативным details; содержимое остаётся в серверном HTML.
- Release — творческая идентичность, объединяющая медиасодержание; формат отдельного издания не определяет тип релиза. Никаких вымышленных данных, эффектов, анимаций или 3D.

Публичные URL, права доступа, модель БД и API сохраняются. Переработка Studio — отдельный этап.
