# Экспериментальная главная /v2

Проверено по [коммиту](README.md) от 10.11.2026. **Факт:** [app/v2/page.tsx](../../app/v2/page.tsx) собирает сцены из [components/v2/](../../components/v2/) и [getV2PageData](../../lib/server/v2.ts). Используются существующие релизы, издания, персонажи, серии, места и связи; отдельной схемы контента нет.

Маршрут имеет ISR 60 секунд и `noindex, nofollow`. Главная `/` остаётся отдельной. Сервер отдаёт текстовые ссылки и альтернативу графа; интерактивные части загружаются лениво. Визуальное переключение «Аудио/Книга» не является воспроизведением. **План:** замена основной главной потребует отдельного решения; наличие `/v2` само по себе её не утверждает.

```mermaid
flowchart LR
  Page[/v2] --> Data[getV2PageData]
  Data --> Repos[Репозитории контента]
  Repos --> DB[(PostgreSQL)]
  Data --> Scenes[Серверные сцены и ссылки]
  Scenes --> Lazy[Ленивый граф и медиа]
```
